# Astra Chess — acceptance and interfaces

User chose Astra-authored weights only. Original target: grandmaster-level moves without search, browser app with time controls, consumer-laptop variant, deployed GitHub Pages. Playing strength is a measured research outcome, not promised. No pretrained weights, no training/fitting, no opening book, no engine calls during play. Independent evaluation may use chess engines as opponents, never as policy labels or training.

## Implementation
- New standalone repo; never touch Hermes source. GitHub identity verified: clavum-figendi. Repo target astra-chess; publish after tests and preview.
- Two reproducibly compiled original sparse feed-forward neural circuits, Pocket and Atlas. Raw canonical board one-hot input, plain fixed sparse affine/ReLU evaluator, all scoring logic in saved coefficients/topology. Legal masking uses chess.js, never examines candidate successor positions for score. Larger circuit encodes extra direct tactical relationships; don't pad sizes or claim stronger from larger alone.
- Describe accurately: authored neural chess heuristics, not learned/general intelligence and no established Elo. Count weights AND structural storage, not just a tiny coefficient vector.
- UI: playable responsive chessboard, both colors, promotion, castling, en passant, game-end reporting, clocks (1+0/3+2/5+0/10+5/unlimited/custom), new game/resign/flip, PGN export/FEN import, model selection, download provenance, top candidate logits and latency. Inference Web Worker; generation IDs reject stale replies. Monotonic elapsed-time clocks, AI time included, model loads before clock starts, no timer reset exploit.
- Laptop: same generic Node runtime + downloaded weight files, UCI and move CLI. No GPU or service necessary.
- Test raw encoding, generic runtime, circuit logic, legal outputs, worker integration, clocks, both colors and promotions, cancellation, packaged runtime, real desktop/mobile browsers, hosted-origin response. Benchmark held-out puzzle source and games versus reproducible baselines with exact protocol; no invented Elo.

## Ownership / shared API
Parent: package.json, PLAN.md, tools/build.mjs, tools/serve.mjs, tools/benchmark.mjs, laptop/, docs/, README.md, evaluation/, deployment and integration E2E.
Engine worker: tools/compile-models.mjs, src/network.mjs, src/engine.mjs, public/models/*, tests/engine*.test.mjs, docs/ARCHITECTURE.md.
UI worker: public/index.html, public/style.css, public/app.mjs, public/worker.mjs, src/clock.mjs, tests/clock*.test.mjs, public/pieces/* if needed.

Engine API (same browser and Node):
- src/network.mjs exports parseModel(arrayBuffer) -> model, generic forward(model, input) as appropriate.
- src/engine.mjs exports chooseMove(fen, model) -> { move: string|null UCI, candidates: [{move:string, score:number}], elapsedMs:number }. Pure deterministic model selection from current position, legal-masked, sorted score descending then UCI lexical. Return top five candidates. No fallback alternate chess engine. Exports encodePosition(fen) as useful.
- Model fetch: models/pocket.bin, models/atlas.bin; accompanying models/manifest.json includes models array [{id:'pocket'|'atlas',name,file,bytes,parameters,neurons,...}], formatVersion, provenance, limitations. parseModel consumes binary only.
- Web worker imports '../src/engine.mjs' and '../src/network.mjs'; requests {type:'load',id,modelId}, response {type:'loaded',id,modelId,metadata?}; {type:'move',id,fen} response {type:'move',id,...chooseMove result}; errors {type:'error',id,error}. UI worker owns exact protocol.
- Browser imports chess.js through import map name 'chess.js' -> './vendor/chess.js'; Node uses installed pinned dependency. Build copies public/, src/, dependency ESM module to dist/vendor/chess.js. Worker cannot use import map, so engine should import chess from './chess.mjs'; build copies dependency ESM at dist/src/chess.mjs. In source src/chess.mjs will be generated by parent as a Node re-export of chess.js. Build overrides src/chess.mjs with vendor file. UI should import './src/chess.mjs' relative to index-level app.mjs. Worker imports './src/engine.mjs' (dist/src beside app, not parent directory).
