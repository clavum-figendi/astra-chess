<h2 class="wp-block-heading" id="faq">FAQ</h2>



<p class="wp-block-paragraph"><strong>Q: How to use these files?</strong><br>A: Import them into the database software of your choice such as chessbase or scid. I have tested the files with scid but not with any other software. Please <a href="https://database.nikonoel.fr/tutorial-how-to-use-the-lichess-elite-database/" data-type="page" data-id="50">check out the video tutorial</a> if you are not sure what you should do!</p>



<p class="wp-block-paragraph"><strong>Q: Why aren’t the clock times included?</strong><br>A: To save space.</p>



<p class="wp-block-paragraph"><strong>Q: Why aren’t the URLs of the games included?</strong><br>A: lichess stores the URLs of the games in the “Site” tag. Unfortunately scid has a limit on the number of different sites which can be stored in a database which is reached pretty fast if each game has its own site. I decided to delete the URLs to be able to use the files in scid. From June 2020 I kept the URLs under a new tag called “LichessURL”.</p>



<p class="wp-block-paragraph"><strong>Q: Why would I need to download this database if the lichess explorer has the same games?</strong><br>A: The lichess explorer is great for ad-hoc checking where you went wrong in a game but its inherent restrictions (currently you can only see the top 4 games in a particular position) doesn’t make it as useful as a downloadable database for in-depth opening and middlegame preparation.</p>



<p class="wp-block-paragraph"><strong>Q: Can I generate the database myself to suit my needs better?</strong><br>A: Sure, I use pgn-extract to generate the database, <a href="https://database.nikonoel.fr/script-lichess-elite-database.zip">you can download the scripts I use here</a>. Use them at your own risks but please let me know if you end up doing a cool project with them!</p>



<p class="wp-block-paragraph"><strong>Q: I have a comment or suggestion – how do I contact you?</strong><br>A: Feel free to message me at <a href="https://lichess.org/@/nikonoel">https://lichess.org/@/nikonoel</a></p>
